# Security Policy

## Supported Versions

Current list of versions being supported with security updates.

| Version | Supported |
| ------- | --------- |
| 2.4.x   | Yes       |
| < 2.4   | No        |

## Reporting a Vulnerability

If you find a vulnerability, please report it privately by emailing davedebugs@outlook.com instead of opening a public issue. Include the version you're running and steps to reproduce if possible.
